# 📇 Flashcard Quiz App

## Overview
An interactive flashcard application built with vanilla JavaScript for effective learning and memorization.

## Features
✨ **Interactive Flashcards**
- Click to flip cards and reveal answers
- Beautiful gradient UI with smooth animations
- Study, Add, and Manage modes

🎯 **Card Management**
- Add new flashcards with questions and answers
- Delete cards you don't need
- Automatic data persistence

📊 **Smart Organization**
- Study mode for learning
- Manage tab for editing/deleting
- Progress tracking with card counter

💾 **Data Persistence**
- All data stored in browser's LocalStorage
- Cards saved automatically
- Data persists across sessions
- Offline functionality

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Mobile-friendly design

## How to Use

### Study Mode
1. Click "📖 Study" tab
2. Read the question on the card
3. Click the card to flip and see the answer
4. Use Previous/Next buttons to navigate

### Add Cards
1. Click "➕ Add Card" tab
2. Enter your question
3. Enter the answer
4. Click "Add Card"
5. Your card is saved!

### Manage Cards
1. Click "⚙️ Manage" tab
2. View all your cards
3. Click "Delete" to remove any card

## Installation
1. Download files:
   - index.html
   - style.css
   - script.js
2. Place in same folder
3. Open index.html in browser
4. Start learning!
